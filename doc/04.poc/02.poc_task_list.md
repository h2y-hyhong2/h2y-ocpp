# ELVIS Platform 제품군 및 모듈별 개발 작업 명세서 (Product Task List)

본 문서는 **ELVIS Platform**의 2대 핵심 제품군(**`ELVIS-CONTROL`**, **`ELVIS-CONNECT`**) 산하 **4개 독립 모듈**별로 구현해야 할 상세 개발 항목 및 주요 역할 범위를 정의한 목록입니다.

---

## 1. 제품군 및 모듈 구조 아키텍처 요약

```text
========================================================================================
                               ELVIS Platform Architecture

 │ 1. ELVIS-CONTROL (관제/어드민 제품군)    │   │ 2. ELVIS-CONNECT (충전기/파이프라인 제품군)│
 │                                          │   │                                          │

========================================================================================
```

## 2. `ELVIS-CONTROL` 제품군 개발 작업 목록

### 2.1. `elvis-control-ui` (관제 UI 프론트엔드 | `E-CTL-UI`)
> **주요 기술 스택**: Vue 3, Vite, Pinia, Nginx Reverse Proxy  
> **핵심 역할**: 관제사 전용 웹 포털 및 실시간 상태/이벤트 모니터링 Dashboard

* [ ] **1. 관제 대시보드 & 시각화 화면 구현**
  * [ ] 충전소/충전기/커넥터 단위 실시간 상태 모니터링 (Idle, Charging, Faulted, Unavailable 색상 커스텀)
  * [ ] 실시간 충전 전력(kW), 충전량(kWh), 단가 모니터링 차트 컴포넌트
  * [ ] 충전기 위치 지도(GIS 기반) 시각화 맵 연동
* [ ] **2. 충전기 원격 제어 (Remote Control) UI**
  * [ ] 원격 충전 시작 (`RemoteStartTransaction`) 및 중지 (`RemoteStopTransaction`) 폼/모달
  * [ ] 충전기 리셋 (`Reset`: Soft/Hard), 커넥터 잠금해제 (`UnlockConnector`) 제어 팝업
  * [ ] 단가/설정 변경 (`ChangeConfiguration`) 및 가용성 변경 (`ChangeAvailability`) 인터페이스
* [ ] **3. 실시간 장애/알림 센터 (Notification Center)**
  * [ ] WebSocket 기반 실시간 알림 토스트 (장애 발생, 상태 변경, 충전 완료 등)
  * [ ] 미확인 장애 이력 팝업 및 관제사 조치 이력 등록 UI
* [ ] **4. Nginx 프록시 & SPA 배포 환경 구성**
  * [ ] Vue Router 정적 서빙 및 Nginx Rewrite Rule 설정
  * [ ] `/api` 및 `/ws` 백엔드 역방향 프록시 (Reverse Proxy) 튜닝

---

### 2.2. `elvis-control-api` (관제 백엔드 API 서비스 | `E-CTL-API`)
> **주요 기술 스택**: Java 25, Spring Boot 3.x, Spring MVC, WebSocket Handler  
> **핵심 역할**: 어드민 REST API 제공 및 UI 웹소켓 알림 푸시

* [ ] **1. 어드민 관제 REST API 개발**
  * [ ] 충전소 / 충전기 / 커넥터 자산 및 실시간 상태 조회 API (MySQL 9.71 연결)
  * [ ] 충전 이력 및 거래 내역 상세/조건 검색 API
  * [ ] 시계열 1초/10초 단위 미터값(MeterValues) 및 전력 소비 통계 조회 API (ClickHouse OLAP 이중 조회)
* [ ] **2. 원격 제어 명령 Kafka 발행 (Outbound Producer)**
  * [ ] UI 원격 제어 요청 검증 및 Kafka 하향 커맨드 토픽 (`ocpp-outbound-commands`) 발행
  * [ ] 원격 제어 처리 결과 타임아웃 관리 및 응답 매핑
* [ ] **3. UI 웹소켓 푸시 핸들러 (WebSocket Push Handler)**
  * [ ] Kafka UI 알림 토픽 (`ocpp-ui-notifications`) Listener 구동
  * [ ] 접속 중인 웹 관제 세션 세션 맵 관리 및 WebSocket/SSE 메시지 브로드캐스트 푸시
* [ ] **4. 이중 DB 데이터 조회 서비스 튜닝**
  * [ ] OLTP(MySQL) 자산/원장 쿼리 최적화 및 Caching
  * [ ] OLAP(ClickHouse) 시계열 대용량 쿼리 연결 풀(HikariCP/ClickHouse JDBC) 옵티마이징

## 3. `ELVIS-CONNECT` 제품군 개발 작업 목록

### 3.1. `elvis-connect-ws` (OCPP WS 게이트웨이 | `E-CNT-WS`)
> **주요 기술 스택**: Java 25, Spring Boot 3.x, Spring WebSocket / Netty  
> **핵심 역할**: 충전기 단말 WebSocket 커넥션 수용 및 인바운드/아웃바운드 메시지 중계

* [ ] **1. WebSocket 세션 & 인증 관리**
  * [ ] 충전기 단말 WS Handshake, HTTP Basic Auth 및 토큰 검증
  * [ ] 동시 접속 세션 맵 관리 (충전기 ID ↔ WebSocket Session)
  * [ ] 주기적 Heartbeat 헬스체크 및 비정상 끊김 세션 자동 정리
* [ ] **2. 상향 메시지 수신 & Kafka 인바운드 발행 (Inbound Producer)**
  * [ ] 수신 OCPP Frame (Call, CallResult, CallError) JSON 파싱 & 기본 규격 검증
  * [ ] 수신 패킷 즉시 Kafka 인바운드 토픽 (`ocpp-raw-events`) 발행 (Non-blocking 비동기)
* [ ] **3. 하향 제어 커맨드 수신 & 충전기 전송 (Outbound Consumer)**
  * [ ] Kafka 하향 커맨드 토픽 (`ocpp-outbound-commands`) Listener 구동
  * [ ] 해당 충전기 WS 세션 찾기 및 OCPP 제어 요청 Frame 전송
  * [ ] 충전기 응답(CallResult) 대기 및 타임아웃 타임 핸들링

---

### 3.2. `elvis-connect-sync` (OCPP Consumer 백엔드 | `E-CNT-SYNC`)
> **주요 기술 스택**: Java 25, Spring Boot 3.x, Virtual Threads, KafkaListener, MySQL, ClickHouse  
> **핵심 역할**: Kafka 패킷 소비, OCPP 파싱, DB 이중 적재 및 이벤트 알림 발행

* [ ] **1. Kafka 메시지 소비 & Virtual Threads 병렬 처리**
  * [ ] Kafka `ocpp-raw-events` 토픽 수신 (Java 25 Virtual Threads 기반 대용량 병렬 처리)
  * [ ] OCPP 1.6 / 2.0.1 메시지 동작(Action)별 DTO 데시리얼라이즈 (`BootNotification`, `StatusNotification`, `MeterValues`, `StartTransaction`, `StopTransaction` 등)
* [ ] **2. MySQL 9.71 실시간 마스터 상태 Update**
  * [ ] 충전기/커넥터 최신 상태 (`Status`, `ErrorCode`, `LastHeartbeat`) 트랜잭션 Update
  * [ ] 충전 시작/종료 거래 이력(OperRechgHist) 테이블 생성 및 상태 갱신
* [ ] **3. ClickHouse 시계열 미터값 벌크 적재 (Bulk Ingestion)**
  * [ ] 수신된 `MeterValues` 및 1초 주기 전력 미터링 데이터 버퍼링 (In-Memory Queue)
  * [ ] 버퍼링 데이터 초당/배치 단위 ClickHouse Bulk Insert (Insert Batching)
* [ ] **4. 장애 및 상태 변경 이벤트 발행 (Event Producer)**
  * [ ] 충전기 장애(`Faulted`) 또는 주요 상태 변경 감지 시 Kafka UI 알림 토픽 (`ocpp-ui-notifications`)으로 이벤트 발행

## 4. 모듈 간 데이터 흐름 및 상호작용 정리

| 데이터 흐름 방향 | 발신 모듈 | 수신 모듈 | 전달 매체 / 프로토콜 | 주요 데이터 내용 |
| :--- | :--- | :--- | :--- | :--- |
| **상향 (Upstream)** | 충전기 단말 | `elvis-connect-ws` | WebSocket (OCPP-J) | OCPP 메시지 원문 패킷 |
| **상향 (Upstream)** | `elvis-connect-ws` | `elvis-connect-sync` | Kafka (`ocpp-raw-events`) | 수신된 인바운드 OCPP 패킷 |
| **상향/적재 (Storage)**| `elvis-connect-sync` | MySQL / ClickHouse | JDBC / Bulk Insert | 상태 Update 및 시계열 미터값 벌크 저장 |
| **알림 (Notification)**| `elvis-connect-sync` | `elvis-control-api` | Kafka (`ocpp-ui-notifications`) | 장애 발생 및 상태 변경 알림 이벤트 |
| **푸시 (UI Push)** | `elvis-control-api` | `elvis-control-ui` | WebSocket / SSE | 실시간 관제 대시보드 푸시 메시지 |
| **하향제어 (Downstream)**| `elvis-control-ui` | `elvis-control-api` | HTTP REST API | 원격 제어 요청 (Start/Stop/Reset 등) |
| **하향제어 (Downstream)**| `elvis-control-api` | `elvis-connect-ws` | Kafka (`ocpp-outbound-commands`) | 충전기 하향 제어 커맨드 패킷 |
| **하향제어 (Downstream)**| `elvis-connect-ws` | 충전기 단말 | WebSocket (OCPP-J) | 충전기 전송 OCPP Remote Command |

## 5. 결론 및 개발 우선순위 가이드

1. **Phase 1 (인프라 & 통신 게이트웨이)**: `elvis-connect-ws` 개발하여 충전기 커넥션 및 Kafka 발행 검증
2. **Phase 2 (파이프라인 & DB 적재)**: `elvis-connect-sync` 개발하여 Kafka 패킷 파싱 및 MySQL/ClickHouse 이중 적재 검증
3. **Phase 3 (관제 백엔드 API & 푸시)**: `elvis-control-api` 개발하여 REST API 및 Kafka 기반 UI Push 구현
4. **Phase 4 (관제 UI 프론트엔드)**: `elvis-control-ui` 개발하여 실시간 대시보드 시각화 및 원격 제어 인터페이스 최종 연동
